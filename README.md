# 🐍 Rusty Editor — Browser-Based Python Code Editor

A lightweight, local Python code editor that runs entirely on your machine.
Write Python in the browser, hit **Run**, and see output instantly — with full
support for **NumPy, Pandas, SciPy, Matplotlib, Requests**, and any other
library installed in your Python environment.

The backend is built with **Node.js + Express**. It spawns a Python subprocess
to execute user code, so no Python web framework is needed.

---

## ✨ Features

| Feature | Details |
|---|---|
| **Monaco Editor** | Same editor that powers VS Code — syntax highlighting, auto-indent, bracket matching |
| **All Python libraries** | numpy, pandas, scipy, matplotlib, requests … anything in your Python env |
| **stdin support** | Feed values to `input()` calls via the stdin box |
| **Configurable timeout** | 5 – 30 s dropdown in the toolbar |
| **Save to disk** | Saves code to `workspace/` folder |
| **Keyboard shortcut** | `Ctrl+Enter` runs the code |

## 🗂️ Project Structure & Code Explanation

```
code-editor/
├── package.json           ← Root config. Uses `concurrently` to start both frontend & backend.
├── backend/               ← Node.js / Express
│   ├── server.js          ← Express app serving HTTP API endpoints (`/run`, `/save`, `/health`).
│   ├── executor.js        ← Core logic: Uses `child_process.spawn` to run Python, passing input and capturing output.
│   └── package.json       ← Backend dependencies (`express`, `cors`).
├── frontend/              ← React + Vite
│   ├── src/
│   │   ├── App.jsx        ← Main application logic and state management.
│   │   ├── api.js         ← Functions mapping to the backend REST API (`fetch` calls).
│   │   ├── index.css      ← Styling configuration.
│   │   └── components/
│   │       ├── Editor.jsx       ← Configures the Monaco code editor for Python editing.
│   │       └── Terminal.jsx     ← xterm.js terminal emulator for output/input.
│   └── vite.config.js     ← Frontend build configuration.
└── workspace/             ← Saved .py files land here.
```

**How it works under the hood:**
1. The **frontend** (React/Monaco) captures your code and `stdin` input.
2. Clicking 'Run' sends a `POST /run` request to the **backend** (Express).
3. The backend `executor.js` writes your code to a temporary `.py` file.
4. It calls `child_process.spawn('python')`, handing over the file and injecting the `stdin`.
5. The `stdout` and `stderr` generated by the Python interpreter are captured.
6. The temporary file is securely deleted, and the result is returned to the frontend.
7. Any installed Python module (like `numpy` or `pandas`) works out-of-the-box because Node simply inherits the environment's Python path.

## 🚀 Quick Start

### Prerequisites

| Tool | Version | Download |
|---|---|---|
| **Python** | 3.9+ | https://python.org/downloads/ |
| **Node.js** | 18+  | https://nodejs.org/ |

### 1 — Install Dependencies

Run this from the root `code-editor/` folder to install dependencies for both frontend and backend:

```powershell
npm run install-all
```

### 2 — Start the App

From the root `code-editor/` folder, run:

```powershell
npm start
```

This command uses `concurrently` to start both servers in a single terminal.

| Server | URL |
|---|---|
| Node/Express backend | http://localhost:5000 |
| Vite frontend | http://localhost:3000 |

Open **http://localhost:3000** in your browser. Done!

## 📦 Supported Python Libraries

The editor spawns Python with your full system environment, so every installed
package is available:

```python
import numpy as np       # ✅ arrays, math
import pandas as pd      # ✅ dataframes
import scipy             # ✅ scientific computing
import matplotlib        # ✅ plotting (text/file output; no GUI window in server mode)
import requests          # ✅ HTTP calls
import math, json, os    # ✅ stdlib — always available
```

To add more packages, just run `pip install <package>` in your terminal.

## ⌨️ Using stdin ( the `input()` function )

If your code calls `input()`, fill in the **stdin box** below the editor —
one value per line. They are fed to each `input()` call in order.

**Code:**
```python
name = input("Your name: ")
age  = int(input("Your age: "))
print(f"Hello {name}, you are {age} years old!")
```

**stdin box:**
```
Alice
30
```

## ⚙️ Configuration

| Setting | Where | Default | Notes |
|---|---|---|---|
| Backend port | `PORT` environment variable | `5000` | `$env:PORT=8080; npm start` |
| Execution timeout | Toolbar dropdown | `15 s` | Max 60 s enforced by server |
| Workspace folder | `backend/server.js` `WORKSPACE` | `workspace/` | Relative to `code-editor/` |

---

## 🛡️ Security Notes

- Code runs in a **Python subprocess** — never eval'd inside Node.
- The subprocess inherits `process.env` so installed packages are accessible.
- Designed for **local/personal use** — do not expose port 5000 to the internet
  without adding authentication.

## 🐛 Troubleshooting

| Problem | Fix |
|---|---|
| `Could not start Python` | Make sure `python` (Windows) or `python3` (Linux/Mac) is on your PATH |
| `ModuleNotFoundError: numpy` | Run `pip install numpy` in the same Python env |
| Backend shows "Offline" | Make sure `node server.js` is running on port 5000 |
| `input()` hangs | Fill in values in the stdin box below the editor |
| Port already in use | `$env:PORT=5001; npm start` |
| Execution timeout | Raise the timeout via the toolbar dropdown |
